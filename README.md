# Primera Página Web con Reflex

## Descripción
Este proyecto consiste en una página web desarrollada utilizando Reflex y Python. La aplicación presenta una interfaz con temática oceánica, utilizando tonos azules y botones interactivos que cambian dinámicamente el contenido mostrado en pantalla.

---

## Requisitos

Antes de ejecutar el proyecto es necesario tener instalado:

- Python 3.11 o superior
- Poetry
- Git

---

## Clonar el repositorio

```bash
git clone https://github.com/alissasssst/-Primera-P-gina-Web-con-Reflex.git
```

Entrar a la carpeta del proyecto:

```bash
cd -Primera-P-gina-Web-con-Reflex
```

---

## Instalar dependencias

```bash
poetry install
```

---

## Ejecutar la aplicación

```bash
poetry run reflex run
```

---

## Abrir en el navegador

Después de ejecutar el proyecto, abrir en el navegador:

```text
http://localhost:3000
```

---

## Funcionalidades

- Diseño inspirado en el océano
- Interfaz personalizada con tonos azules
- Botones interactivos
- Cambio dinámico de mensajes utilizando Reflex
